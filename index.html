01 — Introducción y motivación

Por qué hace falta un método más

Imagina tener que resolver a mano un sistema de ecuaciones complejo sin ayuda de una computadora. Para lograrlo, en la década de 1930, Richard V. Southwell desarrolló el Método de Relajación.

Esta metodología permite resolver sistemas de ecuaciones lineales (que siempre pueden organizarse visualmente como matrices). Se trata de un método iterativo: en lugar de buscar la respuesta exacta mediante un despeje directo, parte de un resultado inicial aproximado y lo va "mejorando" ciclo tras ciclo para reducir el error.

Hoy en día, el método de Southwell está en desuso en el ámbito profesional. Las computadoras actuales operan distinto a la mente humana y prefieren algoritmos más mecánicos y rápidos, como los métodos de Jacobi, Gauss-Seidel o SOR.

Entonces, ¿por qué estudiarlo? Porque fue diseñado para la intuición humana, no para las máquinas. Aprender a "relajar" un sistema te enseñará a pensar estratégicamente y te dará una base matemática invaluable para entender a fondo la teoría que veremos a continuación.

02 — Base teórica y teoremas

Base teórica y teoremas

Para aplicar el método de relajación hay una base teórica que tener en cuenta, que concierne a los sistemas de ecuaciones.

Primero, debemos tener un sistema de ecuaciones representable como una matriz:

A·x = b

Donde A·x es un sistema de ecuaciones con A como los coeficientes, x el vector incógnita, y b el vector solución de la ecuación.

Para resolver sistemas de ecuaciones existen dos tipos de métodos:

Métodos exactos o directos

Son algoritmos que resuelven el sistema de ecuaciones con una serie finita de operaciones aritméticas. Conocidos son los métodos de Cramer y Gauss-Jordan.

Métodos aproximados o iterativos

Es el tipo al que el método de relajación pertenece, y se basa en el cálculo progresivo y aproximado de la solución del sistema de ecuaciones. La idea es que, con cada iteración, el resultado del sistema se "mejora", aproximándose al resultado real. Podemos detenernos con el método cuando consideremos que la solución es suficientemente adecuada; para infinitas sucesiones, el resultado converge al real.

03 — El método

El método

  1. Paso 1. Dado nuestro sistema de ecuaciones A·x = b, despejamos el término b igualando a cero, tal que resulte en A·x − b = 0. Llamaremos al término de la izquierda residuo, y lo denotaremos matemáticamente como R. Nos quedan varios residuos:
    a11x1 + a12x2 + ⋯ − b1 = R1
    a21x1 + a22x2 + ⋯ − b2 = R2
    a31x1 + a32x2 + ⋯ − b3 = R3 …
  2. Paso 2. Dividimos, del lado izquierdo del sistema, cada fila i por el valor −aii del sistema. Esto nos garantiza que la diagonal principal del sistema sea igual a −1, y nos será evidente su ayuda a la hora de iterar con el método. Nos queda:
    (a11x1 + a12x2 + ⋯ − b1) / a11 = R1
    (a21x1 + a22x2 + ⋯ − b2) / a22 = R2
    (a31x1 + a32x2 + ⋯ − b3) / a33 = R3 …
  3. Paso 3. Igualamos en el sistema todas las incógnitas a cero (x1 = x2 = ⋯ = xn = 0), lo que resultará en distintos valores para nuestros n residuos. Tomamos la primera fila del sistema y anotamos el valor del residuo de haber igualado a cero; digamos que resultó en R1 inicial (también tendremos R2 inicial, R3 inicial…). Luego generamos un "incremento" de 1 a la variable x1 que habíamos igualado a cero (llamemos a ese incremento Δx1). Nos daremos cuenta de que ese R1 inicial ha cambiado (y también los demás Rn inicial) a otro valor distinto, digamos R1 final. Lo que nos interesa saber es cuánto cambió el residuo R debido a ese incremento, o sea el valor final menos el inicial. Anotamos entonces cuánto cambió el residuo R1 dado ese incremento Δx1, pero también cuánto cambiaron los demás residuos, y lo ponemos en una tabla.
  4. Paso 4. Lo que obtuvimos en el paso 3 nos dice lo siguiente: dado que inicialmente supuse todos los valores de las incógnitas iguales a cero, sé que al aumentar en uno una incógnita que desee (aumentar por alguna Δxn), voy a tener como resultado un aumento en cada residuo correspondiente, respectivamente, a ΔR1, ΔR2, …

    Esta información la voy a usar en este paso: tomando arbitrariamente el residuo más grande o más "estresado", procedo a "relajarlo" cambiando una de estas xn variables para que sea igual a cero.

    El algoritmo es el siguiente: tomo un residuo Ri que es el más "estresado". Luego miro en la tabla, para dicho Ri, alguno de los Δxn. Lo que voy a saber es que, si por ejemplo mi Ri es 5 y un Δxn hace que Ri se reduzca en 1, entonces voy a incrementar cinco veces por ese valor Δxn para que mi residuo Ri se reduzca a 0.

    ΔR1ΔR2ΔR3...ΔRi...ΔRn
    x1 = ⋯ = xi = ⋯ = xn = 0543522...5...2
    x1 = ⋯ = xn = 0, xi = 5503928...0...7
  5. Paso 5. Repetir el paso 4: encontrar el siguiente residuo "más estresado" (el de mayor valor) y volver a buscar un incremento que haga que dicho residuo se haga 0.
  6. Paso 6. Eventualmente, todos los residuos tendrán un valor muy cercano a cero, o en el mejor de los casos, igual a cero. Sea cual sea el caso, esto habrá resultado de haber probado varios n valores para las xn incógnitas. Dichos valores serán el resultado del sistema de ecuaciones.

04 — Teorema del radio espectral

Teorema del radio espectral

El método iterativo, sea cual sea, siempre se puede pensar como una máquina matemática que transforma nuestro sistema original (A·x = b) en un ciclo o bucle con la siguiente forma:

x(k+1) = M·x(k) + c

Teniendo en cuenta que x representa la solución del sistema de ecuaciones, x(n) es sencillamente la enésima iteración resultante de haber aplicado un método iterativo, o la enésima aproximación. M es una matriz de iteración y c una constante, que salen de trabajar el sistema original.

Lo que nos interesa para asegurar que el método funciona es que el error de cada iteración (la diferencia entre nuestra aproximación actual y el valor real) vaya desapareciendo. Está demostrado que el error de la siguiente iteración es igual al error actual multiplicado por esa matriz M:

e(k+1) = M·e(k)

Aquí es donde entra el concepto de Radio Espectral. En álgebra lineal, el radio espectral de una matriz es simplemente su autovalor más grande en valor absoluto. De forma sencilla, lo podemos pensar como el "factor de estiramiento máximo" que aplica esa matriz.

El teorema

El esquema iterativo es convergente si y sólo si se cumple la condición necesaria y suficiente de que el radio espectral de la matriz M es estrictamente menor a 1.

En otras palabras, si el radio espectral es menor a 1 (por ejemplo, 0.8), significa que en cada iteración el error se multiplica por una fracción, encogiéndose un 20% cada vez, hasta eventualmente desaparecer (puesto que el error, para una gran cantidad de iteraciones, terminará encogiendo muy cercanamente al 0%). Si fuera mayor a 1, el error crecería con cada iteración y el método divergiría.
