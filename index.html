Métodos iterativos · Sistemas de ecuaciones lineales

Método de
Relajación

En cada vuelta, el método mira las n ecuaciones del sistema, encuentra la que está más lejos de cumplirse, y corrige únicamente la variable responsable de esa ecuación. Nada más se toca.

Ri(x) = valor propuesto − xi → xi ← xi + Ri

01 — Introducción

De la solución exacta a la aproximada

Un sistema de ecuaciones lineales A·x = b se puede resolver de dos maneras: con métodos directos (Gauss, Cramer, factorización LU), que llegan al resultado exacto en un número finito de pasos, o con métodos iterativos, que arrancan de un vector cualquiera y lo van corrigiendo hasta acercarse mucho a la solución real.

Ya vieron dos métodos iterativos hoy: Jacobi y Gauss-Seidel. Los dos recalculan todas las incógnitas en cada vuelta. El método de Relajación pertenece a la misma familia, pero cambia la estrategia: en cada iteración toca una sola variable — la que más lo necesita.

Idea central

Cada ecuación del sistema le "pertenece" a una incógnita. Relajación mide cuánto le falta a cada ecuación para cerrar en cero, y arregla primero la que está más rota.

02 — Fundamento

Qué es un residuo, exactamente

Para la ecuación i del sistema, despejar xi usando los valores actuales de las demás variables es exactamente lo que hace Jacobi en cada fila. Llamamos a ese resultado el valor propuesto para xi:

Valor que "propone" la ecuación i para xi xi propuesto = ( bi − Σj≠i aij·xj ) / aii

El residuo Ri es simplemente la distancia entre ese valor propuesto y el valor que la variable tiene ahora mismo:

Residuo de la ecuación i Ri(x) = xi propuesto − xi actual

Si Ri da 0, la ecuación i ya está satisfecha con los valores actuales. Cuanto más grande sea |Ri|, más lejos está esa ecuación de cumplirse — y más urgente es corregirla.

Conexión con lo que ya vieron

Esta fórmula es la misma cuenta que hace Jacobi para actualizar xi. La diferencia no está en cómo se calcula el candidato, sino en cuándo se acepta: Jacobi acepta los n candidatos juntos en cada vuelta; Relajación acepta uno solo — el del residuo más grande.

03 — Algoritmo

El procedimiento, paso a paso

  1. Condición de partida: ningún aii puede ser cero (si pasa, se reordenan ecuaciones e incógnitas). Si la matriz es diagonalmente dominante, es más probable que el método converja.
  2. Calcular todos los residuos R1, R2, …, Rn con el vector actual.
  3. Elegir el mayor en valor absoluto: i* = el índice donde |Ri| es más grande.
  4. Corregir sólo esa variable: xi* ← xi* + Ri*. Las demás quedan exactamente igual.
  5. Repetir desde el paso 2 con el vector actualizado, hasta cumplir el criterio de parada.
¿Cuándo paramos de iterar? (Criterios de parada)

En la práctica real no conocemos la solución exacta para compararla. Por eso, el método debe darse cuenta por sí solo cuándo detenerse usando una "tolerancia" (ε). Hay dos formas principales de hacerlo:

  • Por el residuo (Usado en esta calculadora): Se detiene cuando el mayor residuo en valor absoluto es menor a la tolerancia (ej: |Rmax| < 10⁻⁶). Si el residuo es casi cero, significa que las ecuaciones ya "cierran".
  • Por diferencia entre iteraciones: Se detiene cuando la distancia entre el vector nuevo y el anterior es menor a la tolerancia ( ||x(k) - x(k-1)|| < ε ). O sea, cuando iterar ya casi no cambia los valores.

El sistema del apunte, a mano

Sistema de partida:

2x₁ + 15x₂ + 4x₃ = −16

Vector inicial: x⁽⁰⁾ = (0.8, −1.7, 2.5). Solución exacta del sistema (para comparar): (1, −2, 3).

Primera iteración, mostrando cada cuenta

Vector inicial (dato del problema): x₁=0.8, x₂=-1.7, x₃=2.5

Reemplazo esos tres valores en las tres fórmulas de residuo (del sistema transformado):

R₁ = -(0.8) - 0.3×(-1.7) - 0.1×(2.5) + 0.7

  • -(0.8) = -0.8
  • -0.3 × (-1.7) = +0.51
  • -0.1 × (2.5) = -0.25
  • + 0.7
  • Sumo todo: -0.8 + 0.51 - 0.25 + 0.7 = 0.16

R₂ = -0.1333×(0.8) - (-1.7) - 0.2667×(2.5) - 1.0667

  • -0.1333 × 0.8 = -0.1067
  • -(-1.7) = +1.7
  • -0.2667 × 2.5 = -0.6667
  • -1.0667
  • Sumo: -0.1067 + 1.7 - 0.6667 - 1.0667 = -0.1374

R₃ = -0.05×(0.8) - 0.1×(-1.7) - (2.5) + 2.85

  • -0.05 × 0.8 = -0.04
  • -0.1 × (-1.7) = +0.17
  • -(2.5) = -2.5
  • +2.85
  • Sumo: -0.04 + 0.17 - 2.5 + 2.85 = 0.48

¿Por qué elegimos el mayor en valor absoluto?

Ahora tenemos tres números: |R₁|=0.16, |R₂|=0.1374, |R₃|=0.48. El más grande es R₃. La lógica es: la ecuación 3 es la que está "más rota" en este momento, la que más lejos está de cumplirse. Tiene sentido priorizarla — es donde más impacto tiene arreglar algo, y además es la que "controla" x₃.

La corrección — y por qué funciona

La fórmula es: x_i nuevo = x_i viejo + R_i
Para x₃: x₃_nuevo = 2.5 + 0.48 = 2.98

¿Por qué sumarle justo el residuo, ni más ni menos? Porque si volvés a mirar la ecuación de R₃:

R₃ = -0.05x₁ - 0.1x₂ - x₃ + 2.85

x₃ aparece con coeficiente -1. Si a x₃ le sumás una cantidad δ, R₃ cambia en exactamente -δ (porque el coeficiente es -1). Entonces, si quiero que el nuevo R₃ dé cero:

  • R₃_nuevo = R₃_viejo + (-1)×δ = 0
  • 0.48 - δ = 0
  • δ = 0.48

O sea: el incremento que hay que sumarle a la variable para que su ecuación cierre exacto es justo el residuo. ¡Sale directo de que el coeficiente de la diagonal vale -1 en el sistema transformado!

Nuevo vector: x₁=0.8 (no se tocó), x₂=-1.7 (no se tocó), x₃=2.98

07 — Balance

Ventajas y limitaciones

Ventajas

Simple de aplicar a mano en sistemas chicos. Cada paso ataca directamente el mayor error del momento, lo que suele acelerar la convergencia frente a corregir todo por igual. Fácil de seguir con una tabla, sin álgebra matricial pesada.

Limitaciones

Hay que recalcular todos los residuos en cada vuelta sólo para saber cuál es el mayor, lo que implica más comparaciones que Jacobi o Gauss-Seidel. Para sistemas grandes resueltos a mano se vuelve tedioso. Al depender de "cuál es el peor ahora", es menos directo de paralelizar que Jacobi.
